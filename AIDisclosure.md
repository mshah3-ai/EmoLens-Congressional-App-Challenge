# AI Disclosure — EmoLens

This disclosure describes how AI was used in EmoLens, based on the developer’s account.

## AI during development

I wrote the application code myself. I used AI tools for **debugging assistance**, such as understanding error messages, troubleshooting problems, and discussing possible fixes. I reviewed and applied any fixes myself.

## AI used by the application

EmoLens integrates **Anthropic’s Claude API** to power its optional **Ask EmoLens chatbot** and related opt-in AI features. Claude is used to respond to users within the app; integrating this API is different from using an AI coding agent to write the application’s source code. The app’s other pattern and forecasting calculations use its separate statistical model.

## Responsibility and transparency

I am responsible for the code, design decisions, testing, and the application’s behavior. This statement reflects my description of how I used AI in the project.
